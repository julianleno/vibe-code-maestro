# Maestro Memory Index

This directory is the canonical persistent memory for the project.

## Read order

1. `PROJECT.md` — stable product and domain context
2. `STATE.md` — current phase, blockers, validation, next action
3. `DECISIONS.md` — consequential decisions and rationale
4. `LEARNINGS.md` — verified reusable lessons
5. newest relevant files in `sessions/`

## Rules

- Verify memory against the repository and runtime.
- Do not store secrets or full transcripts.
- Update `STATE.md` before ending meaningful work.
- Add a short session checkpoint under `sessions/`.
- Archive stale session files instead of loading all history.
