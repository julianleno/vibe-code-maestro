# UI/UX Intelligence

Use project goals, audience, brand constraints, content density, platform, and reference material to produce:

- interface principles
- information hierarchy
- layout system
- token architecture: primitive, semantic, component
- typography and spacing scales
- responsive rules
- component states
- empty, loading, error, and success states
- keyboard and screen-reader behavior
- usability review checklist

## External enhancement

The repository can install UI/UX Pro Max using its official CLI rather than redistributing its data:

`npx uipro-cli init --ai <platform>`

Preserve its upstream license and attribution. Treat generated suggestions as inputs to review, not automatic design truth.
