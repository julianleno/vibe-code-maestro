# Accessibility Audit

Target WCAG 2.2 AA unless the spec states otherwise. Run automated checks, then perform manual keyboard, zoom, focus-order, form-label, error-announcement, reduced-motion, and screen-reader-oriented reviews. Automated success never replaces manual review.
