# Security Review

Use OWASP ASVS and application-specific threat modeling. Verify trust boundaries, authentication, authorization, tenancy, input handling, output encoding, file upload controls, secrets, logging, dependency risk, database policies, and abuse controls. Findings require severity, evidence, impact, remediation, and retest status.
