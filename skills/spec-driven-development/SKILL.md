# Spec-Driven Development

## Workflow

1. Inspect repository reality.
2. Run the intake question engine.
3. Write the project specification and acceptance contract.
4. Record architectural decisions.
5. Create vertical delivery slices.
6. Map every requirement to tests and release gates.
7. Reject implementation that cannot be traced to a requirement.

## Definition of ready

A slice is ready only when its actor, outcome, constraints, acceptance criteria, data impact, error states, and validation commands are explicit.
